# Online Shopping System

A basic MySQL database project for an online shopping system.

## Tables

- customers
- products
- orders

## Features

- Store customer information
- Store product information
- Store order information
- Connect customers with products through orders
- Track quantity, order date, total amount and order status

## Technologies

- MySQL
- phpMyAdmin
- XAMPP
- SQL

## Database

Database name:

`shopping_db`

## Purpose

This project demonstrates basic relational database concepts and SQL operations for an online shopping system.
